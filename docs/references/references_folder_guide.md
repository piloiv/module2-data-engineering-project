# References Folder Guide

Use this folder for source material that explains the assignment, business context, prior decisions, or supporting research.

Good files to keep here:

- Assignment briefs and rubrics
- Business model notes
- ChatGPT or stakeholder conversation exports
- Source PDFs, Word documents, or text notes
- Reference screenshots or diagrams used for planning

Avoid putting final deliverables here. Final writeups belong in `docs/`, slide decks belong in `slides/`, notebooks belong in `notebooks/`, and runnable code belongs in `src/`, `sql/`, `dbt/`, or `dashboard/`.

Suggested naming:

- `module2_project_assignment.pdf`
- `business_model_notes.md`
- `chatgpt_project_conversation.md`
- `stakeholder_requirements.md`
